    <h1>🏏 IPL 2022 Performance Analysis</h1>

    <h2>📌 Project Overview</h2>
    <p>
        This project analyzes the performance of players and teams in the 
        <strong>Indian Premier League (IPL) 2022</strong> using Python libraries such as 
        <strong>Pandas, Matplotlib, and Seaborn</strong>.
    </p>

    <p>
        The analysis focuses on identifying top-performing players, team statistics, 
        and match insights through graphical visualizations and data analysis techniques.
    </p>

    <h2>🚀 Technologies Used</h2>
    <ul>
        <li>Python</li>
        <li>Pandas</li>
        <li>Matplotlib</li>
        <li>Seaborn</li>
        <li>Jupyter Notebook</li>
    </ul>

    <h2>📊 Features</h2>
    <ul>
        <li>Player of the Tournament Analysis</li>
        <li>Highest Run Scorer (Orange Cap)</li>
        <li>Highest Wicket Taker (Purple Cap)</li>
        <li>Team Performance Comparison</li>
        <li>Match Win Statistics</li>
        <li>Graphical Representation of IPL Data</li>
    </ul>

    <h2>📂 Dataset</h2>
    <p>
        The dataset contains IPL 2022 player and match statistics including:
    </p>

    <ul>
        <li>Runs scored</li>
        <li>Wickets taken</li>
        <li>Strike rates</li>
        <li>Economy rates</li>
        <li>Match results</li>
        <li>Team standings</li>
    </ul>

    <p><strong>Dataset Source:</strong> Kaggle / Public IPL datasets</p>

    <h2>📈 Visualizations Included</h2>
    <ul>
        <li>Top 10 Run Scorers</li>
        <li>Top 10 Wicket Takers</li>
        <li>Team Winning Statistics</li>
        <li>Most Valuable Player Analysis</li>
        <li>Toss Impact Analysis</li>
        <li>Boundary Distribution Charts</li>
    </ul>
